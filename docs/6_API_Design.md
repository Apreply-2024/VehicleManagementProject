# API Design

## Vehicle APIs

### Create Vehicle

POST /vehicles

Purpose:

Add a new vehicle.

---

### Retrieve All Vehicles

GET /vehicles

Purpose:

Return all vehicles.

---

### Retrieve Vehicle by ID

GET /vehicles/{vehicle_id}

Purpose:

Return a single vehicle.

---

### Update Vehicle

PUT /vehicles/{vehicle_id}

Purpose:

Update vehicle information.

---

### Delete Vehicle

DELETE /vehicles/{vehicle_id}

Purpose:

Remove a vehicle.
