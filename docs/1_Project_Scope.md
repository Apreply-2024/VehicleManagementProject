# Vehicle Management System

## Purpose
The Vehicle Management System provides APIs to manage vehicles within a fleet. The system allows users to create, retrieve, update, and delete vehicle information.

## Objectives
* Manage vehicle information.
* Provide REST APIs for external applications.
* Ensure data validation and consistency.
* Support future database integration.

## In Scope
* Add new vehicles.
* View all vehicles.
* View vehicle details.
* Update vehicle information.
* Delete vehicles.
* Search vehicles.

## Out of Scope
* User authentication.
* Role management.
* Vehicle tracking using GPS.
* Notifications.
* Dashboard UI.

## Users
* Fleet Manager
* Administrator

## Technology Stack
* Python
* FastAPI
* Pydantic
* PostgreSQL (future)
* SQLAlchemy (future)
